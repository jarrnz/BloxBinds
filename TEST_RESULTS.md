# Test results — BloxBinds 1.3.0 Beta

Final optional-feature expansion tested on Windows 11 x64, Python 3.12.14, Tk 8.6 and PyInstaller 6.22.3. Version remains 1.3.0 Beta.

- Focused feature suite: 43 passed. The earlier 42-feature/27-UI runs also passed; final review added export-overwrite protection, reset confirmation and sound cleanup regressions. The full 187-test intermediate run passed before those last guards; the final 190-test run passed afterward.
- Existing coverage passed for all nine slots, single/combination precedence, left/right modifiers, Mouse3/4/5, injected input exclusion, duplicate replace/cancel, reserved shortcuts, settings migration, physical modifier cleanup, automatic detection, focus transitions, F10/chat pause persistence, emergency stop, backquote, experimental Inventory Mode, calibration/drag refusal, tray and hook cleanup.

Network responses are mocked; no real API availability claim is made.
- Startup: current-user registration, spaces/quoting, removal, missing/moved executables, opt-in-only path repair, startup arguments, tray fallback and duplicate-instance handling. Registry access is mocked; tests never register real Windows startup or perform sign-in.
- Indicator: all relevant engine statuses, shared window/tray/indicator state, manual pause across focus changes, one window, show/hide, native non-activation style, drag/persist, negative monitor coordinates, disconnected/off-screen monitors, recovery and cleanup. Display fixtures simulate monitor layouts; native tests use the current desktop.
- Backups: portable JSON round-trip, local startup/position exclusion and preservation, invalid/duplicate JSON fields, unsupported schemas, unexpected/missing fields, invalid/reserved/duplicate shortcuts, validated preferences, compatibility reset, confirmation/cancellation, atomic save failure and protection against overwriting live settings. ## Native Windows and release verification

- Source smoke and staged executable smoke **passed on the normal Windows desktop**: nine visible slots, unclipped 570×790 window (requested 489×776), native keyboard/mouse hooks, real tray startup, and clean shutdown. Remapping and Quick-Move stayed OFF.
- Native status-indicator show/hide/reopen test passed on both the restricted test desktop and the normal desktop: visible mapped label, WS_EX_NOACTIVATE style, no change to the foreground window, and clean destruction. No keys or mouse actions were simulated.
- An initial sandbox UI run failed because its temporary directory could not be saved/removed; tests were rerun using a workspace temporary directory. A sandbox smoke failed because its desktop lacked a usable system tray; the identical smoke passed on the normal desktop. These were harness restrictions, not hidden product failures. Final automated results above have no failures/skips.
- One final executable build was staged separately from the old release. PE metadata and bundled modules verified: Windows x64, FileVersion/ProductVersion 1.3.0, BloxBinds Beta, wirru, and all five feature modules. Executable smoke and audit passed before packaging/promotion. Windows/source ZIP CRC, member allowlists, executable content, and SHA-256 checksums are verified during release preparation.
- Privacy scan passed for **41 public files and 311 bundled code modules**, with relative Python code filenames and no scanned local developer identifiers. **65 upstream runtime account-directory references** remain disclosed in PRIVACY_AUDIT.md. Static inspection does not guarantee anonymity.
- Public wirru/GitHub noreply configuration and both existing commit identities checked without printing identifiers. MIT unchanged. No commits, pushes, tags, history rewrites, visibility changes or publication.

## Testing limits and manual checks

Quick-Move remains experimental, unverified and OFF by default. The earlier owned-window input probe skipped when Windows denied foreground focus; it was not rerun here and no new physical-hardware/Roblox input verification is claimed.
